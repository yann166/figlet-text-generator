# Figlet Text Generator

A simple Python command-line program that converts text into ASCII art using different FIGlet fonts.

## Features

- Generate text using a random font if no font is specified by the user.
- Choose a specific font.
- Display the result directly in the terminal.

## Requirements

- Python 3
- PyFiglet

## Installation

Install the required library:

```bash
pip install pyfiglet
```

## Usage

Run the program:

```bash
python figlet.py
```

If no font is specified, the program automatically selects a random font.

To choose a specific font:

```bash
python figlet.py -f slant
```

You can also use `--font` instead of `-f`.

For more font examples, visit the [FIGlet Fonts Examples](https://www.figlet.org/examples.html) website.
